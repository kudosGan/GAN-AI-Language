## Math with precedence

In the GAN language, you can perform basic math operations like addition (+), subtraction (-), multiplication (*), and division (/). These operations follow the standard mathematical precedence rules, meaning that multiplication and division are evaluated before addition and subtraction. For example, when you write `2 + 3 * 4`, GAN understands that the multiplication should be done first, resulting in `2 + 12`, which equals `14`. The parser in GAN handles this by organizing its functions into layers based on precedence, with the loosest precedence level first and the tightest last.

However, if you try to divide by zero, like in `print(5 / 0)`, GAN will raise a runtime error, as seen in the output: `Runtime error on line 1: division by zero`.

## Comparisons and if/else

In the GAN language, you can use comparisons to check if a value is greater than, less than, or equal to another value. These comparisons return a true or false result, which you can use in if statements. For example, in the code snippet `if x > 5 { print("big") } else { print("small") }`, the program checks if the variable `x` is greater than 5. If it is, it prints "big"; otherwise, it prints "small". You can also use comparisons in the condition of an if statement, like in `if x + 1 >= 8 { print("x plus one is at least 8") }`, which checks if `x + 1` is greater than or equal to 8.

The correct way to write this would be to compare a variable or expression, such as `if x == 3 { print("three") } else { print("not three") }`, which checks if `x` is equal to 3 and prints "three" if true, or "not three" if false.

## Parentheses and negative numbers

In the GAN language, you can use parentheses to group parts of your math expressions, just like in regular math. For example, the line `print((2 + 3) * 4)` will first calculate `2 + 3`, which is `5`, and then multiply that by `4`, giving `20`. Similarly, `print(-5 + 8)` will add `8` to `-5`, resulting in `3`.

Parentheses are used to group expressions tightly, meaning everything inside the parentheses is treated as a single value. For instance, in `print(10 / (2 + 3))`, the expression inside the parentheses `2 + 3` is evaluated first, resulting in `5`, and then `10` is divided by `5`, giving `2`. A minus sign in front of a number, like `-5`, is handled by a special parser level called `parseUnary`, which means `-2 * 3` is interpreted as `(-2) * 3`, resulting in `-6`.

## Scope and final

In the GAN language, variables are created within the block they are defined in, meaning their visibility is limited to that block. For example, in the `scope.gan` code, the `let x = "outer"` line creates a variable `x` that is accessible throughout the entire file. However, inside the `if` block, `let x = "inner"` creates a new `x` that only exists within that block and is not visible outside of it. This is because each block, including `if`, `while`, `for` loops, and function calls, has its own scope. When you exit a block, any variables declared within it are no longer accessible.

Another important feature in GAN is the `final` keyword, which is used to declare a variable that cannot be changed once it is assigned. For instance, in the `final.gan` example, `final daysPerWeek = 7` creates a variable `daysPerWeek` that is set to 7 and cannot be reassigned later. If you try to change its value, like in `final_error.gan`, you will get a runtime error. This ensures that certain values remain constant throughout the program, which can be useful for constants or values that should not be altered.

## Lists

In GAN, you can use lists to store and manipulate collections of items. Lists in GAN are created using square brackets, like this: `let nums = [10, 20, 30]`. The first item in a list is accessed using `list[0]`, so `print(nums[0])` would output `10`. You can also change items in a list by assigning a new value to a specific index, such as `nums[1] = 99`, which changes the second item to `99`. To go through each item in a list, you can use a `for` loop, like `for n in nums { print(n * 2) }`, which will print each item in `nums` multiplied by `2`.

Lists in GAN can hold a variety of items, including other lists. For example, `let names = ["Ann", "Bo"]` creates a list of strings, and `let grid = [[1, 2], [3, 4]]` creates a grid of numbers, where each item in the outer list is itself a list. You can access items in nested lists using multiple indices, such as `print(grid[1][0])`, which would output `3`.

When comparing lists, GAN uses the `==` operator to check if two lists have the same items in the same order. For instance, `print([1, 2] == [1, 2])` will output `true`. However, text in GAN is treated differently; you can index into text to get individual characters, like `print('hello'[1])`, which outputs `e`, but you cannot change text in place. Attempting to access an index that does not exist in a list will result in a runtime error, indicating the number of items in the list. For example, trying to print `a[3]` when `a` only has three items will result in an error message.

`lists.gan`:


- Two names for the same list share it: after let b = a, changing b also changes a (like Python).
- == compares lists item by item, so [1, 2] == [1, 2] is true.
- Text can be indexed ('hello'[1] is 'e') and looped over, but text cannot be changed in place.
- The parser gained a postfix level: after reading a value it keeps reading [index] parts.

## Built-in functions

In GAN, you can use built-in functions that are already defined for you, making your coding experience easier. These functions are listed in `builtins.go` and include operations like `len` for finding the length of a list, `push` for adding items to a list, and `input` for getting user input. For example, to find the length of a list, you would use `len(items)`. If you try to use `len` without providing a list, you'll get an error message saying that `len` expects one argument but got none.

Another useful built-in is `input(question)`, which displays a question to the user and waits for them to type a response. The response is then stored as a string. For instance, if you want to ask the user for their name and age, you can use `name = input("What is your name? ")` and `age = num(input("Age? "))`. The `num(text)` function converts the user's input into a number, so you can perform arithmetic operations with it. If the input isn't a valid number, like when the user types "abc", you'll get an error message saying that the function cannot turn the text into a number.

## Libraries and import

In the GAN programming language, you use the `import` statement to bring in libraries that contain useful functions and constants. For example, the `import "math"` statement loads the math library, which includes functions like `square`, `factorial`, and `isEven`. You can then use these functions by prefixing them with the library name, like `math.square(5)`. The math library also includes a `PI` constant, so you can print `math.PI` to see the value of Pi.

Three core libraries come with GAN: `math`, `text`, and `lists`. The `math` library offers a variety of mathematical functions and constants, while the `text` library provides string manipulation functions, and the `lists` library includes functions for working with arrays. For instance, you can use `math.PI` to get the value of Pi, or `text.repeat("ab", 3)` to repeat the string "ab" three times.

When you import a library, GAN looks for it in the `libs` folder next to the `gan.exe` file, and then in the `libs` folder next to your program. If the library is found, its top-level code runs at the moment of import, which means any `print` statements inside the library will be executed when you import it. For example, if you import the `greeter.gan` module, you'll see "greeter loaded" printed out.

## Types

In the GAN language, you can add type notes to your variables and functions, which the program will check while it runs. These type notes are optional; if you don't add them, the variable can hold any type of value. However, adding a type note means that GAN will check the type every time the variable is assigned a value, every time a function is called, and when the function returns a value. For example, in the `types.gan` file, we see a variable `age` with a type note `number`, which means GAN will ensure that `age` always holds a number.

Types in GAN include `number`, `text`, `bool`, `list`, and `any`. The `any` type means there are no restrictions on what can be stored in the variable. For instance, in the example, `anything: any = 5` allows `anything` to start as a number, but later it can be reassigned to a `text` value, as shown by `anything = "now it is text"`.

When a type check fails, GAN will give you a clear error message indicating what type was expected and what type was actually found. For example, in the `types_error.gan` file, when `count` is assigned a `text` value, GAN throws an error saying that `count` must be a `number` but got a `text` value. These checks happen during the program's runtime, so if a line of code that involves a type check never runs, the error will not be noticed.

`types.gan`:

```gan
// types are optional notes that GAN checks while the program runs
let age: number = 30
final name: text = "GAN"
let items: list = [1, 2]
let ok: bool = true
let anything: any = 5
anything = "now it is text"
print(anything)

func add(a: number, b: number): number {
    return a + b
}
print(add(age, 5))

func greet(who: text): text {
    return "Hello, " + who
}
print(greet(name))

print(typeof(age) + " " + typeof(name) + " " + typeof(items) + " " + typeof(ok))
age = 31
print(age)
```

```

35
Hello, GAN
number text list bool
31
```

- With one, GAN checks it every time the variable is created or changed, every time the function is called with that parameter, and when the function returns.
- The error says exactly what was expected and what arrived: variable "count" must be number but got text.
- any means 'no restriction', so you can write the note and still allow everything.
- These checks happen when the program runs, not before it starts. A wrong type on a line that never runs is never noticed.
- A function with a return type that finishes without returning is an error.
